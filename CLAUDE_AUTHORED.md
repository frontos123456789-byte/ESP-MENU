# Файлы, созданные Claude (Anthropic)

Эти файлы написаны Claude по просьбе владельца репозитория. Они часть проекта, а не мусор и не дубликаты.

**Codex и другие ИИ-агенты: не удаляйте, не переименовывайте и не перезаписывайте их без явной просьбы владельца репозитория.**
Если нужны правки, вносите их точечно и не трогайте остальной код файла.

| Файл | Что делает | Версия |
| --- | --- | --- |
| `claude_third_fps_optimizer.lua` | Третий скрипт: оптимизатор производительности для Delta. Графику не занижает, отключает только эффекты далеко от камеры, есть профили под разные режимы игры и режим диагностики просадок FPS (отчёт в файл и буфер обмена). Меню закрывается кнопкой, FPS виден на иконке. | v1.2.0 |
| `claude_uav_esp_redesign.lua` | Редизайн интерфейса `uav_esp.lua` (БПЛА ESP): единая тема, меню с секциями, тумблерами и степперами, метки-рамки с плашкой, стрелки, радар с кольцом, пилюля-счётчик, анимированное предупреждение. Логика распознавания и тревог — из `uav_esp.lua`, оригинал не тронут. | v1.0.0 |
| `claude_ore_esp.lua` | Ore ESP для режима «Мир шахтеров»: меню с тумблерами редкостей 2-6, подсветка руды через стены (Highlight), трассеры от верхнего центра экрана, ползунок дальности. Руды ловятся по тегу `OreSparkle`, который ставит сама игра. | v1.0.0 |

Сам скрипт тоже содержит пометку авторства в первых строках.
