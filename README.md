# ШТАБ IDE

AI-пространство и браузерный IDE-агент в одном `index.html`: HTML, CSS и JavaScript, без фреймворков и внешних JS-библиотек. CDN используется только для шрифтов и иконок. Остальные файлы репозитория — самостоятельные существующие проекты; приложение их не изменяет.

## Запуск

Открой `index.html` в современном браузере или размести его на статическом хостинге. Сборка и Node.js для использования приложения не нужны.

1. Открой **Настройки** и добавь личный ключ [OpenRouter](https://openrouter.ai/keys) или [Groq](https://console.groq.com/keys).
2. Выбери модель. По умолчанию используется `openrouter/free`; каталог бесплатных моделей загружается из API. Бесплатные квоты, доступность и ограничения определяет провайдер.
3. Выбери Chat, Work или Code. В Code опиши задачу для текущего проекта — агент может изменять его файлы и запускать JavaScript-проверки.

Pollinations использует актуальный API `gen.pollinations.ai`, требует ключ и доступную квоту аккаунта. Это дополнительный провайдер, а не обещание бесплатной безлимитной генерации. Для IDE нужна модель с поддержкой нативных вызовов инструментов; OpenRouter получает требование поддержки `tools`.

## Что делает IDE-агент

- Получает реальное дерево проекта и читает необходимые файлы.
- Создаёт и изменяет файлы, ищет фрагменты, применяет точные замены.
- Запускает JavaScript в изолированном Worker и получает настоящий вывод и ошибки.
- Продолжает цикл после результата инструмента: может исправить ошибку и повторить проверку.
- Проверяет сборку локального HTML-предпросмотра; интерфейс показывает проект в изолированном iframe.
- Сохраняет файлы и историю изменений в браузере. Доступны ручной редактор, импорт текстовых исходников и экспорт проекта ZIP.

Журнал показывает фактически начатые и завершённые операции. Приложение не изображает выполнение shell-команд, установку пакетов или запуск тестов, которых не было. Цикл ограничен числом шагов и объёмом контекста; остановка сохраняет уже выполненные изменения.

## Границы выполнения

Это браузерная IDE для текстовых проектов и JavaScript. Встроенная песочница не предоставляет ОС, Node.js API, Python, npm, сетевой доступ или серверную базу данных. Поддерживаются локальные CommonJS-модули в JS-проверках и локальные ресурсы HTML-проекта в предпросмотре. Для произвольного серверного стека нужна отдельная серверная песочница.

Сгенерированный код запускается в отдельном Worker внутри iframe с непрозрачным origin и ограничивающей CSP. Он не получает API-ключи, DOM приложения или localStorage. Бесконечные вычисления останавливаются таймаутом. Предпросмотр блокирует внешние запросы; неподдерживаемые зависимости нужно заменить локальными или запускать вне приложения.

## Поиск и коннекторы

Веб-поиск включается отдельно. Ключ [Tavily](https://app.tavily.com) даёт поиск по интернету в пределах квоты. Без него доступны ограниченный поиск по открытым источникам и чтение присланных ссылок через Jina Reader. Ошибки и неполнота поиска видны в ответе; время получения страницы не выдаётся за дату её публикации.

GitHub читает профиль, список репозиториев и README выбранного проекта. Vercel читает проекты и последние статусы деплоев, включая выбранную команду. Передача этих данных модели включается отдельным переключателем; по умолчанию после подключения она выключена. Коннекторы внутри приложения выполняют только чтение. Notion, Linear, Figma и Slack явно обозначены как заготовки.

## Данные

Чаты, черновики, тема, шрифт, промпты, ключи и рабочая область сохраняются в localStorage текущего origin. API-ключи хранятся без шифрования: используй личный браузер и ограниченные ключи. Запросы идут напрямую выбранному провайдеру. Поиск передаёт запрос поисковым сервисам, чтение ссылок — Jina Reader. Исходники, которые читает IDE-агент, становятся частью контекста выбранной модели.

Экспорт чатов не включает ключи. ZIP содержит только файлы рабочего проекта. Данные на `file://`, localhost и домене Vercel не синхронизируются автоматически. Если браузер запрещает хранилище или оно заполнено, интерфейс показывает ошибку; сохраняй резервные копии экспортом. Импортированные записи проверяются, а HTML в сообщениях не исполняется.

## Проверка

Для разработки и регрессионных тестов:

```sh
npm ci
npx playwright install chromium
npm test
```

В окружении с системным Chromium:

```sh
CHROMIUM_EXECUTABLE=/usr/bin/chromium npm test
```

Браузерные тесты подменяют ответы AI API, а интерфейс, хранилище и JavaScript-песочница работают по-настоящему. Успешная генерация через личный ключ зависит от его квоты и доступности провайдера. Тестовые ключи не являются рабочими учётными данными.

## Vercel

`vercel.json` публикует только `index.html` из временного каталога `dist`. Серверные функции и переменные окружения не требуются. Тестовые зависимости не устанавливаются во время публикации.
