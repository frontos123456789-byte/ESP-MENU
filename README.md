# Пульт

Бесплатный AI-агрегатор с тремя режимами (Code, Work, Chat), бесплатными моделями OpenRouter,
своими промтами, темами, шрифтами и коннекторами GitHub и Vercel.

Без сборки и зависимостей: статика в `public/` + функции Vercel в `api/`.

## Режим Code как мини-IDE
В Code работает агент. Он сам читает, создаёт и правит файлы проекта, запускает код, открывает превью,
читает ошибки консоли и чинит их. Работает с любой моделью: вызовы инструментов идут обычным текстом,
без tool calling API.

- **Проект.** По умолчанию «Песочница» в браузере (IndexedDB). В Chrome и Edge можно открыть настоящую папку
  на компьютере: файлы читаются и пишутся прямо из браузера, сервер их не видит. Секреты (`.env`, ключи) для агента закрыты.
- **Правки.** Каждое изменение пишется в журнал с диффом и откатывается одной кнопкой. В настоящую папку агент пишет
  только после вопроса с диффом (Настройки → Агент).
- **Превью.** Страницы запускаются в изолированном iframe без доступа к ключам и настройкам Пульта; относительные
  CSS, JS (в том числе ES-модули) и картинки подтягиваются из проекта. Консоль страницы видна агенту и тебе.
- **Публикация.** «Опубликовать» выкладывает проект сайтом на Vercel, «В GitHub» коммитит его в ветку репозитория
  (нужны токены в Коннекторах).
- **Правила проекта.** `AGENTS.md`, `CLAUDE.md` или `.pultrules` в корне подмешиваются в инструкции агента.
- **Горячие клавиши.** Ctrl+K — палитра команд, Ctrl+J — панель проекта, Esc — остановить.

Бесплатные модели слабее платных в многошаговой работе: если агент путает формат, выбери другую модель в шапке чата.

## Запуск локально
```
cp .env.example .env.local    # впиши OPENROUTER_API_KEY
node server.js                # http://localhost:3000
npm test                      # API на моках и юнит-проверки
```

## Деплой на Vercel
1. Залей папку в GitHub-репозиторий и импортируй его в Vercel (Framework Preset: Other).
2. В Settings → Environment Variables добавь `OPENROUTER_API_KEY`.
3. Если сайт публичный, добавь ещё `ACCESS_CODE`, иначе любой сможет тратить твой лимит.

Без серверного ключа каждый вставляет свой ключ OpenRouter в Настройки → Доступ.
С серверным ключом разрешены только модели `:free`.

## Где что лежит
- `public/js/store.js` — режимы, промты по умолчанию, темы, шрифты, хранилище (localStorage)
- `public/js/connectors.js` — коннекторы; новый добавляется объектом в список `CONNECTORS`
- `public/js/settings.js` — вкладки настроек
- `public/js/agent.js` — протокол инструментов агента, разбор и выполнение вызовов
- `public/js/workspace.js` — проект: песочница и папка на компьютере, журнал правок
- `public/js/sandbox.js` — изолированный запуск страниц и кода, сборка html из файлов проекта
- `public/js/panel.js` — правая панель: файлы, превью, консоль, правки
- `public/js/syntax.js`, `diff.js`, `zip.js`, `palette.js` — подсветка, дифф, ZIP, палитра команд
- `api/chat.js` — стриминг в OpenRouter, `api/models.js` — список бесплатных моделей
- `api/github.js`, `api/vercel.js` — прокси к API: чтение, коммит проекта и деплой (токены приходят из браузера в заголовках, на сервере не хранятся)

Чаты, настройки, ключи и токены живут только в браузере пользователя.
